# 🌍 Global Unemployment Data Analysis – Power BI Project

## 📌 Project Overview

This project presents an interactive **Business Intelligence dashboard** developed using **Power BI** to analyze **global unemployment trends from 2014 to 2024**.

The dashboard provides insights into unemployment patterns across **countries, genders, age groups, and time periods**, helping users understand employment challenges worldwide through interactive and visually rich reporting.

---

## 🎯 Problem Statement

Unemployment is one of the most important socio-economic indicators across the world. However, large global datasets often make it difficult to identify:

- Countries with the highest unemployment rates  
- Gender-based unemployment differences  
- Age groups most affected by unemployment  
- Global unemployment trends over time  
- Countries showing major increases or decreases in unemployment  

This project transforms raw unemployment data into meaningful insights using **interactive Power BI dashboards**.

---

## 📂 Dataset Information

- **Dataset Name:** Global Unemployment Data  
- **Time Period Covered:** 2014 – 2024  
- **Countries Covered:** 189  
- **Key Attributes Included:**
  - Country Name  
  - Year  
  - Male Unemployment Rate  
  - Female Unemployment Rate  
  - Youth Unemployment Rate  
  - Adult Unemployment Rate

---

## 🔍 Key Insights

- The **global average unemployment rate shows an overall declining trend** from **2014 to 2024**.
- **Female unemployment** is generally **higher than male unemployment** across many countries.
- **Youth unemployment** is significantly higher than unemployment in other age groups.
- Certain countries consistently show **very high unemployment rates**, making them critical focus areas.
- The **gender gap in unemployment** remains present over the years, though it fluctuates slightly.
- A strong **positive correlation** exists between **male and female unemployment rates**, indicating that both often rise and fall together across countries.
